# Jakarta Premier League website starter

This is a first homepage draft for the JPL website. It is a static website and can be hosted free on GitHub Pages.

## Preview locally
1. Extract this ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox.

## Publish free with GitHub Pages
1. Sign in or create a free account at https://github.com/
2. Create a new **Public** repository named `jakarta-premier-league`.
3. Open the repository and choose **Add file → Upload files**.
4. Upload `index.html` and the `assets` folder (if present), then click **Commit changes**.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait for the deployment to finish. GitHub will show the website address in Settings → Pages. It will look like:
   `https://YOUR-USERNAME.github.io/jakarta-premier-league/`

GitHub's free Pages hosting requires a public repository. The website source is public, and the published website is public too. Do not upload private player information, phone numbers, identity documents, passwords, or other sensitive data.

## Before the public launch
- Replace the `ADD JPL LOGO` placeholder with the official JPL logo.
- Replace the demo team names, fixtures and standings with verified information. Current sample rows are explicitly placeholders.
- Add approved team, player, sponsor and match photographs.
- Confirm season names, dates, champions and historical records.
- Add a privacy notice before collecting player registrations or other personal data.

## Editing
You can edit `index.html` directly in GitHub using the pencil icon. Commit changes to publish updates. GitHub Pages changes can take several minutes to appear.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
